POC Architecture

S.P.A.R.K. ✦

Spreading Positivity and Appreciation through Recognition and Kudos

Email in → AI extracts → Kudos Card out. Buildable in a day.

① Inbound — email becomes a kudos
📧
Shared Mailbox

spark@company.com receives the email

Someone writes a thank-you and CCs spark@. Or forwards a customer email. Nothing else changes for the sender.

⚡ POC: IT creates this mailbox. 30 minutes. No special config.
⚡
Power Automate

Flow triggers instantly

"When a new email arrives in a shared mailbox" — a native connector. Captures sender, recipients, body, timestamp. No code.

⚡ POC: Standard trigger, fires within seconds. Free with most M365 plans.
🤖
Azure OpenAI

AI reads and extracts structured data

A single prompt asks the AI to return JSON: who was recognized, who sent it, what happened in one sentence, which core value it shows, and confidence level.

⚡ POC shortcut: No Azure OpenAI yet? Use AI Builder (M365 native) or hardcode extraction for the demo email. Prove the plumbing first.
🔍
Office 365 Users

Look up the recipient and their manager

Power Automate's built-in connector resolves the recipient's full name, team/department, and manager email from your existing M365 directory. No new data to maintain.

⚡ POC shortcut: Hardcode recipient + manager for the demo. Add lookup in hour 2.
🗄️
SharePoint List

One row written to SPARK_Kudos

Every field saved: who, what, value, team, source, timestamp, confidence. This list is the database. The Hub reads from it. Bumps query it. The Spotlight is generated from it.

⚡ POC: Create the list in 20 min. SharePoint is already in your M365 tenant.
📤
Outlook / Power Automate

Emails sent — Kudos Card + manager notification

Two emails sent automatically. Kudos Card goes to the recipient. Manager notification with a one-click 👏 button goes to their manager. HTML is inline — no external hosting needed.

⚡ POC: mailto: link for the 👏 button (opens pre-filled email). Production upgrade: Outlook Adaptive Cards (requires admin registration).
② Outbound — two emails, two purposes
🌟

Kudos Card → recipient

The magic moment. A clean, designed email with the quote, who sent it, the core value it shows. Nothing else. This email is the product.

✓ Delivers in < 60 seconds
👏

Manager notification → their manager

Short summary of the kudos + one button: "Add my thanks." Clicking opens a pre-filled email to spark@. Manager hits Send. Done. No portal to log into.
