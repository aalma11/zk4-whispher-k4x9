Before you build — 30 min setup

🗂️
Create the SPARK Inbox folder in Outlook
Outlook → New Folder + one mail rule
A
Create a subfolder in your Outlook inbox
Right-click Inbox → New Folder → name it SPARK Inbox. This is the mailbox Power Automate will watch.
B
Create one Outlook rule to route emails into it
Settings → Rules → New Rule. Condition: subject contains "SPARK:" → Action: Move to SPARK Inbox folder.

Tell your team: when sending a kudos, just start the subject with SPARK:
Example: SPARK: Thank you Maria for the benefits outage fix
For the POC, this is your "spark@" address — it's just your own inbox with a subject-line filter. No shared mailbox, no IT ticket.
C
Create a SharePoint List called "SPARK Recognition"
Go to your team's SharePoint site → New → List. Add columns: Date, Recipient, Team, Sender, Source Type, What Happened, Core Value. This is the database and the POC Hub — share the link with your director.

Inbound — Power Automate picks up the email

📥
Trigger: When email arrives in SPARK Inbox folder
Power Automate → Outlook (Office 365) connector
1
Trigger fires on every new email in SPARK Inbox
Connector: Office 365 Outlook. Action: "When a new email arrives in a folder (V3)". Point it at your SPARK Inbox folder. Power Automate polls it — no delay beyond the poll interval (typically 1–3 min).
Office 365 Outlook connector
2
Filter: skip replies, skip your own sent emails
Add a Condition step: if sender email equals your email → do nothing (terminate). This prevents loops when SPARK sends outbound emails and they land back in your inbox.
Condition → terminate on loop

AI extraction — Claude via HTTP

🧠
HTTP action → Claude API → Parse JSON
Power Automate → HTTP connector + Parse JSON
3
HTTP action: POST to Claude API
Power Automate's built-in HTTP action. No connector to install.
// HTTP action settings in Power Automate Method: POST URI: https://api.anthropic.com/v1/messages Headers: x-api-key: <your Claude API key> anthropic-version: 2023-06-01 content-type: application/json Body: { "model": "claude-haiku-4-5-20251001", "max_tokens": 500, "system": "You are SPARK...", "messages": [{ "role": "user", "content": "@{triggerOutputs()?['body/from']} @{triggerOutputs()?['body/subject']} @{triggerOutputs()?['body/body']}" }] }
HTTP connector — no approval needed
4
Parse JSON: extract Claude's response
Add a Parse JSON step. Input: body('HTTP')?['content'][0]['text']. This gives you named variables: recipient_name, what_happened, core_value, source_type, needs_clarification.
Parse JSON step
5
Condition: needs_clarification?
If needs_clarification = true (e.g., "thanks team!" with no name), send a short email back to the original sender with a pre-filled reply: "Quick question — who did you mean to recognize?". Otherwise proceed.
Condition branch

Database — SharePoint List

📋
Create item in SharePoint List
Power Automate → SharePoint connector (native, no config)
6
Write one row to "SPARK Recognition" list
Action: "Create item" in SharePoint. Map each column to the parsed Claude JSON fields. One row per kudos. This is the POC database — and also the production database.
SharePoint connector is native in Power Automate. No HTTP, no API key, no setup. Click the action, sign in, pick your site and list, map the fields. Done.

Outbound — two emails go out

📤
Send email (V2) — Outlook connector
Power Automate → Office 365 Outlook → Send an email (V2)
7
Kudos Card → recipient's inbox
Action: "Send an email (V2)". From: your account. To: recipient's email (looked up from SPARK Roster list). Body: paste the HTML Kudos Card template — Power Automate supports HTML in the email body field, just toggle the rich text editor off and paste raw HTML.
Office 365 Outlook — Send email (V2)
8
Manager notification → manager's inbox
Second "Send an email (V2)" step. To: manager email (from SPARK Roster lookup). Short plain-text email: "Maria just received a kudos from James. [What happened summary]. Here's a quick way to add your thanks:" followed by a mailto: link button — clicking it opens a pre-filled email to Maria.
mailto: button — no Adaptive Cards needed for POC

Mid-morning · 2h

Build steps 1–6: trigger → filter → HTTP (Claude) → Parse JSON → Condition → SharePoint create item.
Afternoon · 1.5h
📤 Outbound emails
Add steps 7–8. Paste HTML Kudos Card template. Wire up variables. Test with a real email sent to your Outlook with "SPARK:" in subject.
Late afternoon · 30min
🎬 Demo
Send one live kudos email. Watch the Kudos Card arrive in the recipient's inbox. Show director the SharePoint list. That's the POC.
What this proves: the core loop — email in → AI understands → beautiful card out → manager notified → everything logged.

Migration to production is minimal: swap the Outlook folder for a shared mailbox (spark@), add a nicer SharePoint page on top of the existing list. The flow logic doesn't change.
